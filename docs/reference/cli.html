CLI 参考

两个命令：trove（交互与运维）和 trove-cli（一次性提问）。 这一页列出全部子命令与 REPL 斜杠命令。

两个入口

命令用途
trove REPL / serve / mcp / admin / job / schedule / maintenance
trove-cli 一次性提问，配合 --print 输出 JSON

pyproject.toml:79 trove main.py:823 main_repl

trove-cli

参数说明
--datasource / -d数据源名或 URL
--config / -f指定配置文件
--model / -m覆盖模型（优先级最高）
--print / -p一次性输出 JSON 后退出
--workflow / -wreflection / fixed / empty
 
echo "哪个地区的平均贷款金额最高?" | uv run trove-cli --datasource demo --print
三个 workflow 分别是什么

reflection 是默认的完整图；fixed 直通不反思（用于对照实验）； empty 是调试用的空转。排查「是不是反思环节引入的问题」时，切到 fixed 跑一遍是很有用的手段。

job / schedule

trove job add | list | cancel
trove schedule --once        # 跑一轮到期任务后退出
trove schedule --daemon      # 常驻循环

daemon 与 serve 内置调度二选一

trove serve 自带调度 tick。再起一个 schedule --daemon 会让任务跑两遍。详见运维管理 · 定时任务。
